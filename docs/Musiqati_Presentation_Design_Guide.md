# أولًا: الهوية البصرية العامة للعرض

## المفهوم الإبداعي (Creative Concept)

**الفكرة المحورية:** "حيث تلتقي الموسيقى بالتكنولوجيا"
*"Where Music Meets Technology"*

يُبنى العرض على ثلاث طبقات بصرية متداخلة:
1. **طبقة الموسيقى** — نوتات، موجات صوت، آلات موسيقية، equalizer
2. **طبقة التكنولوجيا** — دوائر رقمية، شبكة بيانات، واجهات تطبيقات، glow effects
3. **طبقة العمق (3D)** — كروت عائمة، ظلال، mockups موبايل، أشكال هندسية بعمق

الجمع بين هذه الطبقات يعطي انطباعاً أن Musiqati تطبيق ذكي، تقني، وفني في نفس الوقت.

---

## الحالة العاطفية المستهدفة (Mood)

| الشعور | كيف نحققه |
|--------|-----------|
| احترافية عالية | خلفيات داكنة نظيفة، مساحات فارغة واسعة |
| إبداع وابتكار | عناصر glow، أشكال 3D، ألوان نيون |
| ثقة بالمشروع | أرقام واضحة، layout محكم، consistency |
| طابع موسيقي | موجات صوت كزينة، نوتات خفيفة في الخلفية |
| تقني وذكي | خطوط رقمية، أيقونات متناسقة، بيانات منظمة |

### استخدام كل لون:
- **#080810 (Void Black)** → خلفية كل السلايدات
- **#0D0D2B (Deep Space)** → خلفية البطاقات والأقسام
- **#7B2FBE (Electric Violet)** → العناوين، الأزرار، التدرجات
- **#00D4FF (Neon Cyan)** → الخطوط الرقمية، glow effects، الأرقام المميزة
- **#FF2D78 (Neon Magenta)** → أيقونات موسيقية، نقاط تمييز، badges
- **#FFD166 (Gold)** → الأسعار، التحديات، النجاحات، لمسات ذهبية
- **#B8C0CC (Silver)** → النصوص الثانوية، الخطوط الرفيعة
- **#F0F0FF (White)** → كل النصوص الرئيسية

### التدرجات اللونية الرئيسية (Gradients):
```
Gradient 1 — Tech Purple:
  from: #7B2FBE  →  to: #00D4FF  (زاوية 135°)
  الاستخدام: headers، borders مضيئة، شريط العنوان

Gradient 2 — Music Fire:
  from: #FF2D78  →  to: #FFD166  (زاوية 135°)
  الاستخدام: أيقونات موسيقية، badges، تمييز النقاط

Gradient 3 — Deep Space:
  from: #0D0D2B  →  to: #1A0A2E  (زاوية 180°)
  الاستخدام: خلفية البطاقات، panels

Gradient 4 — Glow Overlay:
  from: rgba(123,47,190,0.15)  →  to: transparent
  الاستخدام: overlay شفاف فوق الخلفيات
```

## ✏️ الخطوط (Typography)

### للعرض باللغة العربية:
```
العنوان الرئيسي:  خط Tajawal Bold  (أو Cairo ExtraBold)
                  حجم: 44–52pt  |  وزن: 700–800
                  اللون: أبيض أو التدرج الأول

العناوين الفرعية: خط Tajawal SemiBold (أو Cairo Bold)
                  حجم: 28–36pt  |  وزن: 600
                  اللون: Neon Cyan #00D4FF

نصوص النقاط:     خط Tajawal Regular
                  حجم: 18–22pt  |  وزن: 400
                  اللون: أبيض #F0F0FF

نصوص ثانوية:     خط Tajawal Light
                  حجم: 14–16pt  |  وزن: 300
                  اللون: فضي #B8C0CC
```

### للنصوص الإنجليزية:
```
العناوين الإنجليزية: Poppins ExtraBold  أو  Montserrat Black
نصوص عادية:          Inter Regular  أو  Poppins Regular
أرقام وإحصائيات:     Rajdhani Bold  أو  Orbitron (طابع تقني)
```

### قاعدة التناسق:
- **لا تستخدم أكثر من خطين** في نفس العرض
- التسلسل الهرمي: حجم العنوان دائماً ضعف حجم النص العادي
- المسافة بين الأسطر: 1.4–1.6 للراحة البصرية

## 🎬 SLIDE 1 — سلايد الغلاف / العنوان

### الهدف البصري:
سلايد يُصدم الجمهور بجماله من الثانية الأولى ويثبّت في ذاكرتهم.

### الخلفية:
```
طبقة 1: خلفية أساسية لون #080810 (أسود فلكي)
طبقة 2: دائرة ضبابية كبيرة glow بنفسجي في المنتصف
         → rgba(123,47,190,0.25) بنصف قطر 400px
طبقة 3: شبكة خطوط رقيقة أفقية وعمودية (grid)
         → لون: rgba(0,212,255,0.08) — خفية جداً
طبقة 4: نوتات موسيقية متناثرة في الزوايا
         → لون فضي شفاف opacity 15%
طبقة 5: خطوط موجة صوت (waveform) في الأسفل
         → gradient من cyan إلى violet، opacity 30%
```

### التخطيط (Layout):
```
┌──────────────────────────────────────────────────────┐
│  ●  ○  ○                              [اسم الجامعة]  │  ← شريط علوي رفيع
├──────────────────────────────────────────────────────┤
│                                                      │
│          🎵  [أيقونة 3D موبايل بضوء بنفسجي]          │
│                                                      │
│              ░░░░░░░░░░░░░░░░░░                      │
│           ╔══════════════════════╗                   │
│           ║   M U S I Q A T I   ║  ← اسم كبير جداً  │
│           ║     موسيقاتي         ║                   │
│           ╚══════════════════════╝                   │
│                                                      │
│         [خط glow cyan تحت الاسم مباشرة]              │
│                                                      │
│    "تطبيق محل الآلات الموسيقية — الأردن"             │
│      Musical Instruments Store App — Jordan          │
│                                                      │
│  [Flutter]  [Firebase]  [Bilingual]  [3 Roles]       │  ← chips صغيرة
│                                                      │
│  ════════════════════════════════════════════════    │  ← waveform
└──────────────────────────────────────────────────────┘
```

### التفاصيل:
- **الاسم "MUSIQATI":** حرف بحرف مع مسافات، حجم 64-72pt، تدرج Gradient 1 (violet→cyan)
- **أيقونة 3D:** موبايل مائل بزاوية 15° مع تأثير glow بنفسجي، يُظهر شاشة التطبيق الرئيسية
- **Chips أسفل الاسم:** بطاقات زجاجية صغيرة (glassmorphism) تُظهر التقنيات المستخدمة
- **waveform:** موجة صوت SVG في أسفل السلايد، opacity 40%، لون cyan

### العنصر 3D:
**موبايل 3D مائل** مع شاشة تعرض Home Screen التطبيق، محاط بـ glow بنفسجي ناعم، ظل أسفله.
